## 1. 바꾼 것

| 항목 | 전 | 후 |
|---|---|---|
| 관리자 API | `seller/AdminController` → `SellerService.listForAdmin·updateByAdmin·deleteByAdmin` | `admin/AdminController` → `AdminService.listSellers·updateSeller·deleteSeller` |
| 관리자 계정 만들기 | `seller/AdminBootstrap` → `SellerService.ensureAdmin` | `admin/AdminBootstrap` → `AdminService.ensureAdmin` |
| 관리자 DTO | `SellerDtos.AdminSellerRow·AdminUpdateRequest·AdminSettings` | `admin/AdminDtos` (내용 같음) |
| 이메일 정리(공백 빼고 소문자) | `SellerService` 안 private | `SellerService.normalizeEmail` public static (가입·로그인·관리자 계정 만들기가 같이 씀) |
| `SellerService` 가 쓰던 것 | `GroupBuyRepository`·`CaptureUsageService` (관리자 목록용) | 뺌 |
| 패키지 이름 | `comment`, `notify` | `commentorder`, `notification` (테스트 패키지도 같이) |

- 코드 내용(계산·검사·문구)은 바꾸지 않음. 옮기고 이름만 바꿈
- API 주소·권한(`/api/admin/**` 관리자만)·DB·화면(프론트)은 안 바뀜
- 테스트 코드: `SecurityReviewTest` 가 `SellerService.ensureAdmin` 대신 `AdminService.ensureAdmin` 을 부름. 나머지 관리자 테스트는 URL 로 불러서 그대로

## 2. 패키지 참조 (import 기준) [사실]

- 전: `seller` → `common`·`security`·`groupbuy`·`vision`. `groupbuy`·`vision` 도 `seller` 를 참조해 서로 참조
- 후: `seller` → `common`·`security` 만. `admin` → `seller`·`groupbuy`·`vision`·`common` (한쪽 방향)

## 4. `sellerorder`·`customerorder` 나누기 시험 → 안 함

- 사용자 제안: `order` 는 두고 판매자 쪽(`SellerOrderController`·`SellerOrderService`·`OrderDeletion`)은 `sellerorder`, 고객 쪽(`PublicOrderController`·`PublicOrderService`·`CustomerCancelService`·`PublicPage`·`CustomerDevice`·`CustomerDeviceRepository`)은 `customerorder` 로
- Claude 클라우드 서버에서 실제로 옮기고 import 를 맞춘 뒤 컴파일 [사실]
  - `order` 밖에서 못 부르게 숨겨 둔 클래스 5개가 막힘: `OrderRules`·`OrderUpdate`·`OrderCancellation`·`OrderMapper`·`Delivery`
  - 이 5개를 열자 메서드 13개(`OrderRules.receiveMethod·paymentMethod·pickupPoint·quantities·delivery·shippingFee`, `OrderUpdate.apply·fill·Values`, `OrderCancellation.cancel·cancelForRefund`, `OrderMapper.toMyOrder·toSellerOrder·toSellerOrders`)가 또 막힘. 컴파일러가 단계별로 알려 줘서 더 나올 수 있음
  - 공통 쪽 `OrderUpdate` 가 고객 쪽 `PublicOrderService.MAX_ORDER_AMOUNT` 를 써서 공통 ↔ 고객 서로 참조도 생김
- 판단: 열면 다른 패키지도 주문 규칙을 직접 부를 수 있어 지금보다 약해짐 + `customerorder` 이름이 엔티티 `CustomerOrder` 와 겹침 → 하지 않음. 시험한 변경은 모두 되돌림
