## 2. 테스트 PDF 값 바꿈

  - 기존 테스트의 CSV 머리줄을 토스뱅크 기본값(거래내용·거래금액·거래일자)으로 바꿈

## 4. 같은 날 추가 (사용자 요청)

- 예시 그림을 입금만 있는 깔끔한 지어낸 거래로 다시 만듦 (카드결제·출금·캐시백 줄 없앰). ⑤ 거래 구분 표시 추가
- 거래 구분 값으로 고객 입금이 아닌 줄 빼기: 캐시백·프로모션·카드·이자·출금·지급. 토스뱅크 기본값 거래 구분 "구분", KB국민 "적요"
  - 빼는 글자는 사용자가 보낸 토스 PDF(구분 "캐시백"), 토스 엑셀(거래 유형 "프로모션입금", 플러스 "체크카드결제"), KB PDF(적요 "체크카드") 기준
  - 고객 송금으로 보이는 값(입금·모임원송금·전자금융·FBS입금)은 남는 것을 테스트로 확인 (`BankStatementReaderTest.nonCustomerDepositsAreExcludedByType`)
  - 거래 구분 칸이 파일에 없으면 멈추지 않고 빼지도 않음. 헤더 불일치 알림의 "못 찾은 헤더(컬럼)명"에서도 뺌
- 백엔드 테스트 256개 통과, 프론트 타입 검사 통과

## 5. 그림 PDF 알림창 (사용자 "글씨가 아닌 그림 PDF는 올렸을 때 읽히지 않는다는 알림 처리")

- 미리보기·올리기에서 글자가 그림으로 된 PDF면 알림창 "글자를 읽을 수 없는 PDF입니다. 글자가 그림으로 된 PDF는 읽지 못합니다. 은행 앱 화면 캡처로 올리거나 엑셀로 받아 올려 주세요." (전에는 빨간 안내 칸에만 나왔음)
- 브라우저로 확인: 그림만 있는 PDF 를 [올리기] → 알림창과 안내 칸에 위 문구
- 알림창은 PDF 안에 글자가 하나도 없을 때만 뜸. 그림 위에 글자가 조금 있는 PDF 는 헤더(컬럼) 불일치 알림으로 감 [사실, 코드 기준]

## 6. 암호 걸린 PDF·엑셀 (사용자 "암호 입력칸을 미리 만들고 암호부터 받아서 열어. html 은 안 함")

- 올리기 칸 "파일 비밀번호 (선택)" → 미리보기·올리기 요청에 password 로 보냄. `BankStatementReader.read(…, password)` → PDF `Loader.loadPDF(bytes, password)`, 엑셀 `WorkbookFactory.create(in, password)`
- 오류: `STATEMENT_FILE_PASSWORD_REQUIRED`(비밀번호 없음)·`STATEMENT_FILE_PASSWORD_WRONG`(틀림). 둘 다 알림창. 전의 `STATEMENT_PDF_PASSWORD`("비밀번호 없이 받거나 캡처로")는 없앰
- 비밀번호는 저장·로그 안 함 (요청 칸 로그를 남기는 코드 없음 확인), 올린 뒤 화면에서 비움
- 테스트: `BankStatementReaderTest.encryptedPdfIsOpenedWithPassword`(RC4 40·128, AES 128·256), `encryptedExcelIsOpenedWithPassword`(xlsx Agile, xls RC4), `M3DepositFlowTest.encryptedExcelUploadWithPassword`(올리기 API: 없음·틀림·맞음). 백엔드 259개 통과
- 따로 확인 (Claude 클라우드 서버, 저장소 밖 시험 코드): LibreOffice 가 암호 건 PDF, msoffcrypto 가 암호 건 xlsx 도 열림
- 브라우저: 암호 PDF 를 비밀번호 없이·틀리게·맞게 올리기 → 알림창 두 가지 → 저장됨, 올린 뒤 비밀번호 칸 비워짐

## 7. 확인 못 한 것·남은 것

- 다른 은행 헤더(컬럼)명: 조사 안 함 (사용자가 조사해서 `bank_header` 에 넣기로)
- 은행이 계좌번호를 몇 자리 가리는지 공식 기준 못 찾음. 지금은 보이는 숫자만 비교
- 실제 은행 PDF 원본으로 계좌번호 찾기는 안 해 봄 (테스트 PDF 와 KB·토스 캡처 배치 기준)
- 1시간 규칙: 실제로 "확인 필요"가 얼마나 뜨는지는 써 봐야 앎
- 화면에서 1시간 규칙 표시는 테스트(API 응답)로만 확인, 브라우저로는 안 봄
- 로컬 DB: V1 을 고쳐서 내 맥북의 `backend/data` 를 지워야 함
