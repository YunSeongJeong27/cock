## 1. 바꾼 것

| 항목 | 서버 | 화면 |
|---|---|---|

| 거래내역 은행 고르기 | 미리보기·올리기가 `bankName` 을 받음. 없으면 공구 입금 계좌의 은행 | ① 올리기 칸의 "거래내역 은행" + 그 은행의 헤더(컬럼)명 표시. 자동 인식·직접 지정·저장한 설정 고르기는 뺌 |
| 계좌번호 확인 | `BankStatementReader` 가 머리줄 위쪽에서 계좌번호를 찾음, `AccountNumbers.compare` | 다르면 경고 칸 + [올리기] 때 "그래도 올릴까요?" 확인창 |
| 같은 계좌 공구 공유 | `DepositPools`, `deposit_upload.seller_id·account_key`, 대조·확정·처리 완료·업로드 목록·중복 검사가 묶음 기준. 공구 계좌 변경·삭제 처리 | 공유 안내, "다른 공구 주문으로 보이는 입금" 칸, 주문 고르기에 다른 공구 묶음, 다른 공구 주문 앞에 [공구 제목] |
| 1시간 규칙 | `customer_order.amount_set_at`(금액이 바뀌면 `OrderUpdate` 가 갱신), `DepositMatcher` 시각 비교·가까운 주문부터 | 확인 필요 안내, "주문 N분 뒤 입금" 표시, 기준 설명 창 문구 |

## 2. 테스트 PDF 값 바꿈

- 전에 만든 `backend/src/test/resources/statements/kb-statement.pdf`·`toss-statement.pdf` 에 사용자 캡처에서 옮겨 온 것으로 보이는 값이 있었음: 출금 상대 이름 2개, 가린 계좌번호, 잔액·총액, 가맹점 이름, 거래 시각
  - 그때 어디서 가져온 값인지 기록이 없어 확실하지 않음. 실제 값일 수 있다고 보고 바꿈 [판단]
- 이름·금액·계좌번호·잔액·시각·가맹점을 모두 지어낸 값으로 다시 만들고 테스트 기대값도 바꿈 (`BankStatementReaderTest`)
- 전 파일은 커밋 e255971 에 남아 있음. 기록에서도 지우려면 브랜치 기록을 다시 쓰고 강제로 올려야 함 → 사용자 결정 필요

## 3. 확인한 것

- 백엔드 테스트 전체 통과 (`./mvnw test`). 새로 넣은 테스트
  - `DepositPoolTest`: 같은 계좌 공구 공유(다른 공구 화면에서 확정·처리 완료 반영, 다른 계좌 공구는 안 보임, 공구 삭제 때 남기는 것·지우는 것), 혼자 쓰던 계좌를 바꾸면 거래내역이 따라감, 계좌번호 같음·다름·못 찾음, "국민은행" → KB국민은행 자동 선택, 1시간 규칙
  - `M3DepositFlowTest.bankHeadersReadStatementAndStopOnMismatch`: 헤더 안 맞으면 400·업로드 안 생김, 은행 추가·바꾸기·원래 값으로, 필수 칸 검사, 다른 판매자의 은행 못 씀
  - `SecurityReviewTest`: 다른 판매자의 은행 설정을 못 지우고 못 씀, 설정 목록에 안 보임
  - `AccountNumbersTest`, `BankStatementReaderTest.bankHeaderValuesAndAccountNumber`·`missingBankHeaderColumnsAreReported`, `DepositMatcherTest` 시각 규칙 2개
  - 기존 테스트의 CSV 머리줄을 토스뱅크 기본값(거래내용·거래금액·거래일자)으로 바꿈
- 프론트 `npm run typecheck` 통과
- 화면 (Claude 클라우드 서버의 Chromium, 로컬 샘플 데이터)
  - 은행 헤더(컬럼) 설정 화면·설정 방법 창·수정 칸·은행 추가 칸 (PC 1366, 폰 390 가로 넘침 없음)
  - KB 테스트 PDF 를 토스뱅크로 미리보기 → 알림창 "거래내역 헤더 설정이 잘못됐습니다…" 확인
  - KB국민은행으로 바꿔 미리보기 → 입금 5건, 계좌 다름 경고 → [올리기] 때 확인창 → 저장
  - 데모 공구 2개가 같은 계좌라 대조 화면에 공유 안내가 뜸

## 4. 확인 못 한 것·남은 것

- 다른 은행 헤더(컬럼)명: 조사 안 함 (사용자가 조사해서 `bank_header` 에 넣기로)
- 은행이 계좌번호를 몇 자리 가리는지 공식 기준 못 찾음. 지금은 보이는 숫자만 비교
- 실제 은행 PDF 원본으로 계좌번호 찾기는 안 해 봄 (테스트 PDF 와 KB·토스 캡처 배치 기준)
- 1시간 규칙: 실제로 "확인 필요"가 얼마나 뜨는지는 써 봐야 앎
- 화면에서 1시간 규칙 표시는 테스트(API 응답)로만 확인, 브라우저로는 안 봄
- 로컬 DB: V1 을 고쳐서 내 맥북의 `backend/data` 를 지워야 함
