# 화면 점검 기록 (2026-10-25)

다른 에이전트가 이 파일만 보고 무엇을 했는지 알 수 있게 남긴다. 설계·결정 기준은 `docs/design.md` 그대로이고, 화면 규칙은 design.md "2026-10-25 화면 다듬기"에 짧게 적었다.

- 작업 위치: Claude 클라우드 서버. 기준 코드 = `main` @ fc7d0ce (PR #2 머지), 작업 브랜치 `ccr-5517f9d7-tkydae`
- 사용자 요청: "기본적인 화면부터 UI적으로 이상한 것들 확인하고 고쳐. 예를 들어 버튼인데 글씨가 줄바꿈돼서 다음 줄로 넘어가 있다든가 하는 부자연스럽고 보기 안 좋은 요소들 다 깔끔히. 그 외 문제되는 것도 일단 고쳐 놔"
- 손대지 않은 것: 전날 화면 둘러보기에서 "판단 필요"로 보고한 6가지(댓글 메모에 남는 글자, 확정 뒤에도 남는 판매자 변경 안내, 공구 수정의 [저장하고 주문 받기 시작] 등)는 사용자가 "일단 두라"고 해서 그대로 둠
- 표기: [사실] 직접 실행·측정으로 확인 / [판단] AI 판단

## 1. 어떻게 점검했나

- 실제 앱 실행: jar(백엔드, local 프로필, 새 H2) + Vite 개발 서버(바뀐 화면 코드). 판매자·고객 9명·환불·입금 대조·댓글 주문까지 도는 시나리오로 데이터를 채움
- 폭 6가지(PC 1366·1024, 태블릿 768, 폰 390·360·320) × 화면 상태 약 40가지(첫 화면·로그인·가입·약관, 고객 주문서·배송·픽업·내 주문 찾기·내 주문·수정·취소·환불 신청 칸·멈춤·마감, 판매자 공구 목록·만들기·수정·상세 각 탭·주문 상세·주문 변경·완료 목록, 은행 열 설정, 내 정보, 관리자)를 브라우저(Playwright Chromium)로 열고 화면마다 자동으로 잼 [사실]
  - 줄이 바뀐 버튼·배지·탭·표 머리·통계 숫자·라디오 칸
  - 띄어쓰기가 아닌 곳에서 줄이 바뀐 글자 (예: "확인하세⏎요")
  - 칸보다 긴 placeholder·값, 상자 밖으로 삐져나온 내용, 화면 오른쪽 밖으로 나간 요소, 페이지 가로 넘침
  - 콘솔 오류·경고, 500 응답
- 잰 것과 별개로 폭별 캡처를 눈으로 확인 (표 칸 찌그러짐·붙은 버튼처럼 숫자로 안 잡히는 것)
- 측정 스크립트는 클라우드 서버 임시 폴더에만 있음 (커밋 안 함)

- 남은 "단어 중간 줄바꿈"은 모두 여는 괄호·가운뎃점·화살표 앞에서 바뀐 것 (예: "주문⏎(댓글 집계)", "입금자명⏎·금액", "24,000원⏎→27,000원"). 줄바꿈 규칙상 허용되는 자리라 그대로 둠 [판단]
- 남은 "잘림"은 그대로 둠 [판단]: 320px 폭에서만 잘리는 것(주문 목록 검색 placeholder, 긴 공구 제목·링크 값), 입금 대조의 주문 고르기 선택 칸(폰에서 긴 선택지는 기기 기본 선택 창에서 전체가 보임)
- 고객 화면에서 로그인 확인 요청(`/api/auth/me`)이 401 로 콘솔에 찍히는 것은 로그인 안 한 사람에게 정상 응답이라 그대로 둠
- 기능 확인: 바뀐 화면 코드로 시나리오(공구 만들기 → 고객 주문·수정·취소·같은 번호 재주문 → 판매자 주문 변경 → 수동 입금 확정 → 거래내역 대조 → 환불 신청·처리 → 수령 → 멈춤·마감 → 엑셀 → 댓글 주문 반영 → 설정 → 관리자) 다시 실행, 실패 0 (처음 1건은 점검 스크립트가 바꾸기 전 placeholder 로 칸을 찾던 것. 칸 이름으로 찾게 고친 뒤 "내 주문 찾기" 못 찾음·찾음 모두 확인) [사실]
- `npm run typecheck`, `vite build` 통과 [사실]. 백엔드는 안 바뀌어서 테스트를 다시 돌리지 않음
- 실제 아이폰·갤럭시 브라우저에서는 안 봄 (폰 크기로 맞춘 Chromium). 글꼴이 다르면 글자 폭이 조금 달라질 수 있음
