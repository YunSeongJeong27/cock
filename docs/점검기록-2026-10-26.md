## 확인한 것: 손님 화면의 남은 수량 [사실]
- 지금 손님 주문서에 "남은 수량 N"이 보인다. 판매자가 준비 수량을 넣은 상품만, 남은 수량이 1개 이상일 때만 (`PublicOrder.tsx` 상품 줄, 서버 `remaining`)
- `docs/design.md` "재고: 막지 않고 보여 주고 알림 (2026-10-16, 사용자 결정)"에 "손님 화면: 남은 수량이 1개 이상일 때만 "남은 수량 N" 표시, 0 이하면 수량 표시를 숨김 [결정: 사용자]"로 적혀 있다
- 그래서 재고 안내의 "손님 화면에는 남은 수량이 1개 이상일 때만 보이고" 는 지우지 않고 사용자에게 보고함

## 바꾼 것
- 화면 문구 파일 `frontend/src/texts/*` 전체: 괄호 설명 → 문장으로, 문장을 잇는 쉼표 삭제
- 칸 이름·안내: 괄호 설명은 칸 아래 작은 글씨나 placeholder 로 옮기거나 지움
  - 예: "닉네임 (밴드·카톡, 선택)" → "밴드·카톡 닉네임", "주문 마감 일시 (비우면 직접 마감할 때까지)" → 칸 이름 + 아래 안내, "비밀번호 (8자 이상)" → placeholder "8자 이상"
- "(으)로" 를 받침에 맞게: `texts/common.ts` 의 `josa()` (입금자명 안내 "꼭 **김딸기**로", 댓글 답글 예시, 주문 변경 안내, 환불 이름 확인)
- 개인정보처리방침·이용약관 초안: 괄호 설명 → 문장. 내용은 그대로
- 서버 문구: `ErrorCode`·`Notice` 의 괄호 설명과 "이(가)"·"은(는)" ("'%s' 상품은 …" 처럼 값 뒤에 조사가 오지 않게), 쉼표. 현장결제 상태 이름 "예약됨 (현장결제)" → "예약됨". 변경 기록의 "(없음)" → "없음"
- 그대로 둔 것 [판단]: 개수 표시 "전체 (6)", 예시 값 안의 괄호 "동해기정떡 2차 (10/15 입고)", 엑셀 열 이름 "입금(원)", 로그 문장
